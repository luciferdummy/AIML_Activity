# Data Science Salary Prediction

This project aims to predict data science salaries using a Linear Regression model. It covers the essential steps of a machine learning workflow:

1.  **Data Loading & Initial Cleaning:** Loading `ds_salaries.csv` and removing duplicates.
2.  **Exploratory Data Analysis (EDA):** Visualizing salary distributions and relationships with experience levels.
3.  **Data Preprocessing:** Handling categorical features by grouping less frequent categories and creating dummy variables.
4.  **Feature Scaling & Data Splitting:** Preparing data for the model by scaling numerical features and splitting into training/testing sets.
5.  **Model Training:** Training a Linear Regression model.
6.  **Model Evaluation:** Assessing the model's performance using R-squared score and actual vs. predicted plots.

## Technologies Used

-   Python
-   Pandas (for data manipulation)
-   Matplotlib & Seaborn (for visualization)
-   NumPy
-   Scikit-learn (for machine learning models and preprocessing)
